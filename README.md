# ZetLite Android

Editor Markdown ultraleve para Android, inspirado no [Zettlr](https://docs.zettlr.com/en/).

- Notas = arquivos `.md` numa pasta (padrão: `/sdcard/ZetLite`)
- Realce de sintaxe, links `[[wiki]]`, backlinks, `#tags`, busca global
- Tabelas, rodapés `[^1]`, citações `[@chave]` a partir de arquivos `.bib`
- Prévia, exportação HTML e PDF, modo foco, meta de palavras, tema claro/escuro
- Sem bibliotecas de terceiros

O APK é gerado pela aba **Actions** e publicado em **Releases**.
